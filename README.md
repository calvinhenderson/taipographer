## 📌 Overview

Taipographer is a custom 30-key mechanical keyboard designed for efficiency, flexibility, and stenography support. Built on the Taipo layout (a streamlined,
productivity-focused keyboard layout), this keyboard contains additional keys for stenography input (e.g., the Stenograph system), making it
ideal for users who prioritize speed and precision in typing.

The keyboard is built using ZMK firmware, allowing for customizable layers, keymaps, and advanced automation. The name "Taipographer"
combines Taipo (the base layout) with stenography (the added functionality), reflecting its dual-purpose design.

## 🧠 Key Features

- Taipo Base Layer: A modified Taipo layout optimized for productivity and ergonomics.
- Stenography Layer: Additional keys for stenography input (e.g., Stenograph or Plover), enabling rapid text entry.
- 30-Key Design: Compact and efficient, with a focus on speed and minimalism.
- Custom PCB: Handcrafted or designed for modularity, supporting your preferred switches and keycaps.
- ZMK Firmware: Full customization for layers, macros, and key mappings.
- Stenography: The stenography layer is designed for users familiar with stenography systems (e.g.
[Plover](https://www.openstenoproject.org/plover/)) with plans for integrating steno directly in the firmware.
- Compact Design: The 30-key layout prioritizes speed and minimalism, making it ideal for portable use.

## 🧱 Hardware

- PCB: Custom 30-key layout.
- Switches: [Kailh Choc Pink](https://www.aliexpress.us/item/3256807315238527.html).
- Keycaps: [Low Profile Choc PBT Keycaps - Black](https://www.aliexpress.us/item/3256806548230734.html).
- Optional Features: [Phone Stands](https://www.aliexpress.us/item/3256804636390824.html) for adjustable tenting.

## 🧠 Software

- Firmware: [ZMK](https://github.com/zmkfirmware/zmk) (open-source, highly customizable).
- Keymap: [config/taipographer.keymap](config/taipographer.keymap) includes base layers, but [config/combos.dtsi](config/combos.dtsi) has the meat.
