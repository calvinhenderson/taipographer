## 📌 Overview

Taipographer is a custom 30-key mechanical keyboard designed for ergonomics,
flexibility, and minimalism. The keyboard is designed around the Taipo layout
(a streamlined, productivity-focused keyboard layout), and contains additional
keys for optional stenography input.

The keyboard is built using ZMK firmware, allowing for customizable layers,
keymaps, and advanced features. The name "Taipographer" combines Taipo (the
base layout) with stenography (optional functionality), reflecting its
dual-purpose design.

## 🧠 Key Features

- Taipo Base Layer: A modified Taipo layout optimized for productivity and ergonomics.
- Integrated Touchpads: Integrates two TPR48 modules for ergonomic mouse input.
- 30-Key Design: Compact and efficient, while supporting optional stenography input.
- ZMK Firmware: Full customization for layers, macros, and key mappings.

## 🧱 Hardware

- PCB: Custom 30-key layout.
- Switches: [Kailh Choc Pink](https://www.aliexpress.us/item/3256807315238527.html).
- Keycaps: [Low Profile Choc PBT Keycaps - Black](https://www.aliexpress.us/item/3256806548230734.html).
- Touchpads: [Azoteq TPR48](IQS572.md)
- Optional Features: [Phone Stands](https://www.aliexpress.us/item/3256804636390824.html) for adjustable tenting.

## 🧠 Software

- Firmware: [ZMK](https://github.com/zmkfirmware/zmk) (open-source, highly customizable).
- Keymap: [config/taipographer.keymap](config/taipographer.keymap) includes base layers, but [config/combos.dtsi](config/combos.dtsi) has the meat.
- Touchpads: [IQS572](IQS572.md)
