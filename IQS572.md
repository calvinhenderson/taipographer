# IQS572

The [TPR48-P201-S](https://www.mouser.com/en/ProductDetail/Azoteq/TPR48-P201-S?qs=HXFqYaX1Q2z2E77WdNGl1Q%3D%3D)
uses the IQS572 IC. This module comes preloaded with GPIO Gesture firmware and
**does not include the I2C bootloader**. However, you can still run trackpad
firmware on these modules by replacing the IQS572 IC with one that includes the
bootloader.

## I2C Bootloader

The `-S` series modules **DO NOT** include a bootloader. Therefore, you cannot program
them over I2C as shipped. You must replace the onboard IC with the
[IQS572BLQNR](https://www.mouser.com/en/ProductDetail/Azoteq/IQS572BLQNR?qs=PzGy0jfpSMsrVXY%2Flkeung%3D%3D)
and flash the Azoteq IQS5xx-B000 trackpad firmware first. Azoteq provides the
necessary resources to do this. The firmware can be flashed with a 3V3 Arduino.

## Pinout

The module solder pads labeled on the TPR48-P201-S module have been verified to
connect to the following pins on the IQS572 IC.

| Label | IC Pin | Description |
| - | - | - |
| (C5) | 7 | NRST |
| IO4 | 9 | Not connected |
| IO5 | 8 | RDY |
| GND | 5 | VSS |
| 3V3 | 4 | VDDHI |
| IO1 | 3 | SCL |
| IO2 | 2 | SDA |
| IO3 | 1 | Not connected |

## ZMK Driver

I have written an [input driver](https://github.com/calvinhenderson/zmk-iqs5xx-input-driver)
for the IQS5xx series chips.

The driver includes many built-in options for customization as well as support for
overwriting any I2C register after normal firmware initialization. This allows the
user to perform in-depth firmware customization without needing to reflash the IC.
